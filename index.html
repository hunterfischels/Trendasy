How it works

1

Pull prices

Daily closes for every ETF come from Yahoo Finance. No data entitlement? A deterministic offline fallback keeps the app running anywhere.

2

Score momentum

Each theme gets a blended score: 1-week, 1-, 3-, 6-month and 1-year trailing returns, weighted toward the medium-term trend.

3

Rank & roll up

Leaders and laggards surface on a heat-mapped leaderboard, and category averages show where capital is rotating.

Run it yourself

git clone https://github.com/hunterfischels/Trendasy.git
cd Trendasy
pip install -r requirements.txt
streamlit run streamlit_app/app.py

Or deploy to Streamlit Community Cloud with main file streamlit_app/app.py.
